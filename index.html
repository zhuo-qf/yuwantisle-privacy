一引言

《渔王岛》（以下简称“本游戏”）是一款由卓庆番（以下简称“我们”）开发的单机休闲游戏。 我们充分理解个人信息对您的重要性，并严格遵守《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》 《中华人民共和国数据安全法》以及工业和信息化部《App 违法违规收集使用个人信息行为认定方法》等法律法规与监管要求。

本政策旨在清晰、准确、完整地说明：本游戏会处理哪些信息、为什么要处理、如何处理，以及您对这些信息享有哪些权利。 请您在使用本游戏前仔细阅读并充分理解本政策，特别是以加粗形式提示的内容。 当您点击“同意”时，即表示您已阅读并同意本政策所述的信息处理方式。

一句话概括：本游戏是纯单机游戏，没有账号体系，不会上传您的存档与个人信息； 唯一涉及第三方数据采集的，是我们接入的 TapADN 广告 SDK —— 且仅在您明确同意后才会初始化。 若您选择“不同意”，游戏仍可完整游玩，只是无法使用“看广告领取奖励”类功能。

三我们收集与不收集的信息

3.1 本游戏不收集的信息

为消除您的疑虑，以下信息本游戏不收集、不上传、不共享：

  • 手机号、身份证号、真实姓名、电子邮箱等可用于识别您真实身份的信息；
  • 通讯录、短信、通话记录、相册、摄像头、麦克风、地理位置（GPS）；
  • 您的游戏存档（金币、船只、天赋、图鉴、昵称等）。

您的游戏进度与设置（如昵称、金币、音量）仅保存在您设备本地的存储空间中， 不会上传至我们的服务器。卸载游戏或在系统设置中清除应用数据，这些本地数据将被一并删除且无法恢复。

3.2 广告功能相关的信息

本游戏包含“观看激励视频广告领取奖励”的可选功能（例如补充体力、退还赌局本金）。 该功能由第三方广告 SDK 提供，只有在您于首次启动弹窗中点击“同意”后，SDK 才会初始化并开始工作。 在此情况下，广告 SDK 可能收集以下信息：

信息类别具体内容

设备基础信息 设备品牌、型号、制造商、操作系统版本、屏幕分辨率与密度、设备语言与时区、CPU 信息、可用存储空间与总内存、系统重启时间、运营商信息
网络信息 IP 地址、网络类型与连接状态、Wi-Fi 状态与信号强度、Wi-Fi 名称（SSID）、BSSID、基站信息
应用信息 应用包名、应用版本号、应用前后台状态、运行中的进程信息、已安装应用列表
传感器信息 加速度传感器、陀螺仪传感器、线性加速度传感器、磁场传感器、旋转矢量传感器

关于传感器与位置：上述传感器与位置信息由广告 SDK 用于识别模拟器、防范广告作弊以及广告地域定向， 本游戏自身的玩法不使用任何传感器数据。本游戏不会请求定位权限，位置信息由 SDK 依据 IP / Wi-Fi 推断得出。

六信息的使用目的与法律依据

我们（及上述第三方 SDK）处理您的信息，仅用于以下明确、合理的目的：

  1. 向您提供激励视频广告，并在您完整观看后发放对应的游戏内奖励（如体力、退还赌局本金）；
  2. 广告效果统计与归因，用于评估广告投放效果、结算广告收益；
  3. 反作弊与安全风控，识别模拟器、虚假点击、批量刷奖励等异常行为，保障广告主与您的合法权益；
  4. 保障服务稳定性，收集崩溃与性能数据以减少闪退、提升加载成功率。

法律依据：上述处理均基于您的同意（《个人信息保护法》第十三条第一款第（一）项）。 您有权随时撤回该同意，撤回后我们将停止相应的信息处理，且不影响撤回前基于同意已进行的处理活动的效力。

我们不会将您的信息用于：个性化推荐以外的自动化决策（如大数据“杀熟”）、 与上述目的无关的商业推广、或任何违反法律法规的用途。

七信息的存储、期限与安全

7.1 存储地点

本游戏不设有服务器，也不向任何自有服务器传输数据。您的游戏存档仅存储于您的设备本地。 广告 SDK 所采集的信息存储于其境内服务器（中华人民共和国境内），不涉及跨境传输。

7.2 存储期限

广告 SDK 采集的信息保存期限遵循其官方隐私政策的规定，通常为实现上述目的所必需的最短时间。 达成目的或您撤回同意后，相关信息将被删除或匿名化处理，法律法规另有规定的除外。 您设备本地的游戏存档在您卸载游戏或清除应用数据时即被删除。

7.3 安全措施

  • 广告请求与素材传输采用 HTTPS 加密通道；
  • 广告 SDK 对设备标识符进行去标识化 / 匿名化处理（优先使用 OAID 等可重置标识符）；
  • 我们仅在必要范围内接入 SDK，并通过代码层面确保未经您同意不初始化任何广告 SDK。

尽管我们已采取合理的安全措施，但互联网环境并非绝对安全。 如不幸发生个人信息安全事件，我们将按法律法规要求及时告知您并向主管部门报告。

八信息的共享、转让与公开披露

  • 共享：除本政策第五条列明的广告 SDK 外，我们不会与任何第三方共享您的个人信息。广告 SDK 系直接在其服务器间完成数据处理，我们不接触、不留存这些数据。
  • 转让：我们不会转让您的个人信息。若因合并、分立、解散、被宣告破产等原因确需转让，我们将告知您接收方的名称与联系方式，并要求其继续履行本政策义务。
  • 公开披露：我们不会公开披露您的个人信息。依法需要公开披露时，我们会单独取得您的同意。
  • 法定例外：根据法律法规、诉讼争议解决需要，或应行政、司法机关的合法要求，我们可能依法提供必要信息。

十未成年人保护

本游戏不面向 14 周岁以下的儿童，也不会主动收集儿童的个人信息。 若您是未满 14 周岁的儿童，请在监护人的陪同下阅读本政策，并在取得监护人同意后再使用本游戏。

若您是未成年人的监护人，当您对被监护人的个人信息有疑问，或发现我们在未获监护人同意的情况下收集了未成年人的信息， 请通过本政策第十二条的方式联系我们，我们会在核实后尽快删除相关信息。

  • 若您不同意变更后的内容，您可以选择停止使用相关功能或卸载本游戏。
